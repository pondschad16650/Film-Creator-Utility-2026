## FAQ

### Is VideoPatch safe to use?

Yes, VideoPatch is a standalone Windows utility that modifies local application files. It does not connect to the internet, install background services, or contain bundled software.

### Which Windows versions are supported?

VideoPatch is designed for Windows 10 and Windows 11 (64-bit). It may work on Windows 8.1 but is not officially tested.

### Does this work with the latest versions of the video editors?

VideoPatch is updated regularly to support the most recent stable releases of CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi.

### Will I receive updates after patching?

No, applying a patch modifies the current installation. Major updates to the video editor may overwrite the patch, requiring you to run VideoPatch again on the new version.

### Is this tool legal?

VideoPatch is intended for educational and personal evaluation purposes. Using it to compatibility licensing for commercial use may violate software terms of service and local laws. The developers are not responsible for misuse.

### Why does my anticomponent flag the executable?

Some security software may issue false positive warnings due to the patching mechanism. You can verify the file's integrity via the provided SHA-256 hash on the repository page.

### Can I use VideoPatch on macOS or Linux?

No, VideoPatch is a Windows-only desktop application. The patching methods are specific to the Windows versions of the supported video editors.

### What if a video editor isn't detected?

Ensure the editor is installed in its default directory. If not, you may need to manually specify the installation path in the VideoPatch interface.

### Does it work with trial versions?

VideoPatch typically works with both trial and installed licensed versions of the software. It aims to unlock features, not change the core license status.
